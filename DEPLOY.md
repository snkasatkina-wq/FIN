# Развёртывание (Docker на вашем компьютере)

## Требования

- Docker Desktop установлен и запущен на вашем ПК
- Файл `УУ2025 - оптим.xlsx` в папке проекта

## Подготовка

1. **Файл данных** — скопируйте `УУ2025 - оптим.xlsx` в папку `data/`:
   ```
   __Финансы/
   └── data/
       └── УУ2025 - оптим.xlsx
   ```

2. **Переменные окружения** — в корне проекта создайте `.env`:
   ```
   OPENAI_API_KEY=sk-...
   TELEGRAM_BOT_TOKEN=...
   TELEGRAM_CHAT_ID=...
   ```

## Запуск

```bash
cd "c:\Users\snkas\OneDrive\Desktop\_ЭТЭ\__Финансы"

# Сборка и запуск
docker compose up -d --build
```

## Проверка

- Логи: `docker compose logs -f`
- Статус: http://localhost:8000/
- Ручной запуск: http://localhost:8000/run

## Поведение

- **При старте** — проверка выполняется сразу
- **Ежедневно в 13:45 МСК** — автоматический запуск
- **GET /run** — принудительный запуск в любой момент

## Важно

Приложение работает, пока Docker Desktop запущен и контейнер не остановлен. Если выключить ПК — контейнер остановится, при следующем включении запустите снова:

```bash
docker compose up -d
```
