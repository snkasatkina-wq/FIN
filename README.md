# Система автоматической обработки выписок из банка

Автоматизированная система для загрузки выписок из банка из почты (mail.ru), обработки PDF файлов и добавления данных в реестр с формированием отчетов.

## Возможности

- ✅ Автоматическая загрузка выписок из почты (mail.ru, Gmail, Outlook)
- ✅ Обработка PDF выписок из банка
- ✅ Автоматическое добавление операций в реестр
- ✅ Формирование отчетов по операциям

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Для работы с PDF через tabula-py требуется Java (JDK 8 или выше). Скачайте и установите Java с [официального сайта](https://www.java.com/).

3. Создайте файл конфигурации `email_config.txt` на основе `email_config.txt.example`:
```bash
copy email_config.txt.example email_config.txt
```

Заполните файл своими данными:
```
email_type=mail.ru
email_address=your_email@mail.ru
password=your_password
subject_keywords=выписка,карточка,счет
days_back=7
```

## Использование

### Основной скрипт

Запустите главный скрипт:
```bash
python main.py
```

Скрипт выполнит следующие действия:
1. Подключится к почте и загрузит последнюю выписку
2. Обработает PDF файл и извлечет операции
3. Добавит новые операции в реестр (файл "УУ2025 - оптим.xlsx")
4. Сформирует отчет

### Ручная обработка PDF

Если у вас уже есть PDF файл выписки, вы можете обработать его отдельно:
```python
from pdf_processor import PDFStatementProcessor
from pathlib import Path

processor = PDFStatementProcessor(Path("выписка.pdf"))
operations = processor.process()
```

### Обновление реестра из Excel

Если у вас есть Excel файл карточки счета (как раньше), используйте:
```bash
python update_reestr_from_51.py
```

или

```bash
ОбновитьРеестр.bat
```

## Структура проекта

- `main.py` - главный скрипт для автоматической обработки
- `email_fetcher.py` - модуль для работы с почтой
- `pdf_processor.py` - модуль для обработки PDF выписок
- `update_reestr_from_51.py` - модуль для обновления реестра из Excel
- `report_generator.py` - модуль для формирования отчетов
- `email_config.txt` - конфигурация почты (создайте на основе example)
- `requirements.txt` - зависимости Python

## Настройка почты

### Mail.ru

1. Включите IMAP в настройках почты:
   - Зайдите в настройки почты mail.ru
   - Включите доступ по IMAP
   - Используйте обычный пароль или создайте пароль приложения

2. В `email_config.txt` укажите:
```
email_type=mail.ru
email_address=your_email@mail.ru
password=your_password
```

### Gmail

Для Gmail требуется пароль приложения:
1. Включите двухфакторную аутентификацию
2. Создайте пароль приложения в настройках аккаунта
3. Используйте этот пароль в конфигурации

## Формат данных

Система ожидает PDF выписки из банка с таблицами операций. Поддерживаются:
- Таблицы, извлекаемые через tabula-py
- Текстовые данные, парсимые через pdfplumber

Операции должны содержать:
- Дата операции
- Документ
- Реквизиты
- Счета дебета/кредита
- Суммы операций
- Назначение платежа

## Отчеты

Отчеты формируются автоматически и содержат:
- Общее количество операций
- Суммы дебета и кредита
- Сальдо
- Детализацию по месяцам

Отчеты сохраняются в файлы вида `Отчет_YYYYMMDD_HHMMSS.xlsx`

## Устранение неполадок

### Ошибка подключения к почте

- Проверьте правильность логина и пароля
- Убедитесь, что IMAP включен в настройках почты
- Для Gmail используйте пароль приложения, а не обычный пароль

### Ошибка обработки PDF

- Убедитесь, что установлена Java (для tabula-py)
- Проверьте, что PDF файл не поврежден
- Попробуйте открыть PDF в другом приложении

### Не извлекаются операции

- Проверьте формат PDF выписки
- Возможно, требуется настройка парсера под конкретный формат банка
- Попробуйте обработать файл вручную через `inspect_excel.py` для анализа структуры
